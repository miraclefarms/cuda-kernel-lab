## 三个阻塞项

这三条任何一条不成立，第 03 篇的测量口径就得改，所以**开工第一件事就是验证它们**：

1. **ncu 计数器权限** — 拿不到就没有计数器级证据，只能 wall-clock + 带宽利用率推断
2. **锁频权限** — 拿不到就不报绝对 TFLOPS，改用会话内相对比值
3. **MIG 与独占状态** — MIG 实例下没有完整 SM 视图，cluster 行为受限，数据不可比
